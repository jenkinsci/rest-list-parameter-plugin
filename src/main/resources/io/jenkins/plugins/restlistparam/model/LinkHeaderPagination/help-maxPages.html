The maximum number of pages to request per value fetch, counting the first request. Allowed are values from 1 to 100, the default is 10.

When the limit is reached while the last page still points to a next page, the values fetched so far are used and a warning is logged, so the list may be incomplete. Test Configuration reports this as a warning.

Every page is a separate request made while the Build with Parameters form renders, so a high limit can make that form slow to open. Each page is cached for the Cache Max Age.
